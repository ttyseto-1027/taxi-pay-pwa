管理者権限管理・管理者プロフィール修正 v13（2026-07-27 JST）

実装内容
1. 管理者権限と組合員区分を分離
   - 管理者でも betaAllowlist / users の利用者情報を読み込む
   - 管理者が組合員なら、組合員向け機能と管理画面の両方を利用可能
   - 乗務員番号・営業所も通常どおり表示

2. 管理者権限の表示
   - 登録ユーザー一覧に「管理者権限」列を追加
   - 「管理者」「一般利用者」を表示
   - 有効な管理者数をサマリーに表示

3. 管理者権限の付与・解除
   - 「管理者にする」「管理者解除」ボタンを追加
   - 誤操作防止のため、対象者のGoogleアカウント再入力を要求
   - 権限付与・解除の実行者UID・メールと日時をadmins文書へ記録
   - 権限解除後も通常の利用者情報と組合員機能は維持

4. 安全対策
   - 現在ログイン中の管理者は、自分自身の管理者権限を解除できない
   - 現在ログイン中の管理者自身は削除できない
   - 管理者ユーザーを削除する場合はadmins文書も削除

5. Firestore
   - 現在のルールにある admins の管理者向け
     list/create/update/delete 権限で動作します
   - Firebase Authenticationのユーザー自体は削除しません

反映後の確認
- 管理者本人が一度ログアウトし、再ログインする
- ヘッダーに登録済み乗務員番号と組合員区分が表示される
- 組合員向けダッシュボードが利用できる
- 管理画面の登録ユーザー一覧に管理者権限列が表示される
