管理画面デザイン・利用者削除機能 v12（2026-07-27 JST）

実装内容
- 管理画面の登録ユーザー一覧に赤い「削除」ボタンを追加
- 事前登録マスター一覧にも「編集」「利用停止／再開」「削除」を表示
- 削除時は誤操作防止のためGoogleアカウントの再入力を要求
- 登録ユーザーの削除対象
  users/{uid}
  v13LoginSuccess/{uid}
  紐づく betaAllowlist/{email}
- Firebase Authenticationのユーザー自体はブラウザ管理画面から削除しない
- メイン画面の乗務員情報バッジを白地・青文字に変更
- 「ユーザー管理」を金色背景・濃色文字に変更
- ログアウトボタンを白地・濃色文字に変更
- 管理画面タイトルを金色に変更
- 管理操作ボタンを青・緑・紫・赤で分類
- 管理画面 v12、Build 20260727-v12

Firestoreルール
現在使用中のルールでは管理者に
betaAllowlist / users / v13LoginSuccess の delete 権限があるため、
今回の削除処理を利用できます。

注意
削除したユーザーを再度利用させる場合は、管理画面から事前登録をやり直してください。
